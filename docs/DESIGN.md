# Dococa FM デザイン資料（DESIGN.md）

本人確定 2026-11-05。画面を作る・直すときは、まずこの資料と模型 `docs/design/station-mock.html` に合わせる。実装の正本は `public/app.css`。ここに無い判断が要るときは、模型に当ててから本人に見せる。

## 1. 一文と空気

- 「世界のどこかにいる誰かの好きなものが聴こえてくるラジオ」
- テイスト: レトロフューチャー / シティ・ポップ。夜の部屋でラジオをつけている感じ。モダンなレイアウトに、ラジオの意匠（トグルスイッチ、ノブ、目盛り、ON AIR）を乗せる。
- 爽やかさを保つ: 地は冷色（空色 / 紺）、差し色だけ暖色（サンゴ・レモン・マゼンタ）。暖色を面に広げない。
- 文言はラジオの言葉で、短く。数字で人や作品を測る表現（件数・順位・一致率）は出さない。

暖色の使いどころ（これ以外には広げない）:

- wordmark `Dococa FM` のグラデーション（coral → magenta 70% → lemon）
- パネル上端の 4px の帯（coral → lemon 55% → magenta）
- `ON AIR`、見出しラベル（いま流れている / このあと流れるもの）、コントロールのラベル: coral
- 目盛り: coral（不透明度 .55）。針: lemon（`box-shadow: 0 0 8px`）
- お便りの左線: lemon。ボタンの枠: coral。主ボタン（私も）: magenta の塗りに白文字
- 作品種別ラベル（音楽 / 映画 / 本 / 動画）: magenta
- 作品のジャケットが無いときの代替: coral → magenta のグラデーション

テーマ切替: 既定は端末に合わせる。ヘッダに ライト / ダーク / 端末 の 3 択。`html[data-theme]` を切り替え、`localStorage` に保存（読めなくても動く）。

## 3. 書体と文字

- wordmark（`Dococa FM` だけ）: `"Righteous"`（Google Fonts）。他に使わない。
- 見出し・本文（日本語・英語とも）: `"Zen Kaku Gothic New"`（Google Fonts、400 / 500 / 700）。フォールバック `"Hiragino Kaku Gothic ProN", system-ui, sans-serif`。
- 太い角ゴシック（Dela Gothic One など）は使わない（本人の判断）。
- 大きさ: wordmark `clamp(28px, 4vw, 40px)`、タグライン `clamp(14px, 1.5vw, 16px)`（PC 幅は 1 行、スマホ幅は折り返す）、作品名 18px / 700、本文 14px、ラベル 11〜12px / 字間 .08〜.1em。
- 行間 1.6。ラベルは字間を広げる。数字は `tabular-nums`。

## 10. 動きと音

ラジオの手ざわり（Phase 6 Task 13）。控えめであることが決まりで、足すときもこの枠の中に収める。

決まり:

- 動きは一度に 1 つ。一つの動きは 300ms 以内が基本（例外は下の表に書いた長さだけ）。
- 続く動きは 2 つだけ: 電源が入っている間の目盛りの針のゆらぎ（±6% を 20 秒で往復）と、声に合わせた ON AIR のランプの明るさ（±15%）。ホームのキービジュアルの電波の弧のゆれは、ラジオが ON のときだけ（OFF では止まって描かれている）。
- 音は 3 つまで: スイッチ、ダイヤル、私も。どれも音量のつまみに比例し、既定は小さい。ラジオが OFF の間は鳴らさない（スイッチを切る音だけは切る瞬間に鳴る）。
- `prefers-reduced-motion: reduce` では動きをすべて止める（スイッチのつまみの移動も。音は残す）。
- 数字・順位はどこにも出さない。お便りの文字は変えない。読んでいる行の印は、オンエア欄の `いま` の行の細い線だけ。

| 場面 | 動き・音 | 長さ |
|---|---|---|
| スイッチを入れる | 目盛りの針が左から一度だけ振れて止まる（「電波を探しています…」が出るのと同時）。ON AIR が出るとき（回が流れ始めるとき）に、ランプが 1 度またたいて点く。低いクリック（三角波 110Hz、音量 × 0.08） | 600ms（針、ランプ）、20ms（音） |
| スイッチを切る | 同じ低いクリック | 20ms |
| ダイヤルを回す | 目盛りごとに針が跳ぶ。「カチ」（矩形波 1800Hz、音量 × 0.05）。OFF の間は鳴らない | 10ms |
| 音量のつまみを回す | つまみが 2° 傾き、針の影がずれる（CSS だけ） | 120ms |
| 声が流れる | クラウドの声の大きさで ON AIR のランプの明るさが ±15% 動く（`AnalyserNode`。新しいメーターは出さない。声が鳴っている間だけ動かし、ほかは止めておく）。ブラウザの声、Safari（macOS と iOS。つないだ声が無音になることがあるため、つながない）、つなぐのに失敗したときは動かないだけで、再生は止めない | 続く |
| 読んでいる行 | オンエア欄の `いま` の行で、左の縦線に重なる 1px の `--lemon` の線が、その作品の語り（冒頭の一行・紹介・手渡し・お便り・ひとこと）の進みに合わせて下へ動く | 300ms |
| お便りのカードを押す | カードの絵が縮みながらラジオの面へ飛ぶ（FLIP、`img.flight`）。一度に 1 枚。そのあと今までどおりそのお便りから流れる | 300ms |
| 私も | ボタンが一度ふくらむ（1.08 → 1）。面から小さな封筒が浮かんで消える。やさしい音（正弦波 880Hz、音量 × 0.04）。件数は出さない | 300ms、封筒 1 秒 |
| モーダルから送ったあと | モーダルが閉じるときに、面に封筒が線で描かれ、少しして消える | 描く 400ms、消えるまで 1.4 秒 |
| 回が替わる | BGM を 2 つの `<audio>` で等パワーのクロスフェード（cos / sin）。BGM の音量（声の下 0.3 × 音量）は変えない。iOS では音量を変えられないので、フェードせずにすぐ切り替える | 1.5 秒 |
| 深夜（端末の時計で 23:00〜4:59） | ラジオの面の `--lemon` を 1 段あたたかく（`html[data-night]` で `--lemon-night`: ライト `#ffb547`、ダーク `#ffc978`）。読み込み時と 1 時間ごとに見直す | 動かない |
| ホームのキービジュアル | 絵の電波の弧に重ねた 1 本の SVG の線（`.kv-waves`）が、ON の間だけ ±3° ゆっくり揺れる（`html[data-on-air]`） | 6 秒で往復 |
