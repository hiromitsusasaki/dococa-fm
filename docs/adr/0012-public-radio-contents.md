# 0012 公開ラジオは、持ち主のお便りと、一言を返したお便り

- **Status:** Accepted
- **Date:** 2026-11-05（公開ラジオを作る）、2026-11-07（中身を決め直す）

## Context

設計の v2 候補に「自分の好きなものを集めた番組を固定 URL で公開し、プロフィール等に貼れる」がありました。マッチングはしないが、「私の好きなもの」を番組という器で見せるのは押しつけにならない、という考えです。2026-11-05 の Phase 2 で、サインインした人が「〇〇さんのラジオ」を公開できるようにしました。

最初は持ち主の「好きなもの」（登録した作品）で番組を組んでいました。けれども 2026-11-06 に「お便りの無い作品は番組に入れない」と決めたため（追記 K）、好きなものを登録しただけでは中身が空になりがちでした。中身も持ち主の言葉ではありませんでした。

## Decision

公開ラジオの中身は、次の 2 つにします（追記 O）。

- 持ち主が送った公開のお便り。
- 持ち主が一言を返した（公開になった）お便り。

好きなものの登録からは作りません。

## Consequences

- 公開ラジオは「この人が何を好きで、何に心が動いたか」を、その人の言葉と、その人が応えた誰かの言葉で聴く場になった。
- 持ち主自身が聴いても、持ち主のお便りが流れる。自分のラジオでは自分のお便りは流れないので、そこが違う。
- 中身が無ければ「まだお便りがありません」と出す。
- 公開に出るのはラジオネームとお住まいだけ。Google の名前とメールアドレスは出さない。URL はサインインした時点で乱数の slug が付き、あとで変えられる。
- ホームには「お便りが届いた公開ラジオ」を新しい順に 5 つまで並べる。数も順位も出さない。
- 「好きなもの」の登録と Spotify の取り込みは、好みにも公開ラジオにも使わなくなった。ハッカソン後に撤去する。
