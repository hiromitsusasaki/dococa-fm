# 0009 MCP を作って、外した

- **Status:** Superseded（2026-11-06 に撤去）
- **Date:** 2026-11-04（作成）、2026-11-06（撤去）

## Context

当初の設計では、同じ台本を 3 つの出口から出す予定でした。アプリの画面、クラウドの声、そして MCP（Claude や ほかのアシスタントのアプリから番組を取り出す口）です。デモでは「同じ回を Claude のアプリから取り出し、Claude の声で読ませる」場面を考えていました。

## Decision

Phase 1（2026-11-04）で remote MCP（Streamable HTTP、設定画面で発行するトークン）を作り、番組の取得・お便りの投稿・反応の 3 つの道具を出しました。

Phase 4（2026-11-06）で外しました。

- 事前生成（[0008](0008-units-and-thumbs-up-loop.md)）で、番組はアプリの中でいつでも声つきで流れるようになり、MCP で取り出す必要が薄れた。
- 聴く体験の中心ではなかった。ほかのアシスタントの中では「原文を変えない」を保証できない、という弱みもあった。
- 経路を減らすと、守る面（認証・レート制限・セッションの例外）も減る。

## Consequences

- `/mcp` のルート、設定の表示、MCP の依存 2 つ、関連するレート制限とセッションの例外を外した。コードは git の履歴に残る。
- DB のトークンの列は残して使わない（migration を増やさないため）。
- デモの 3 場面目は、ホームの「いま届いているお便り」のカードを押すとそのお便りから鳴り、「私も」と一言を返すところに替えた（設計書 §6、2026-11-07）。
- 審査の「Claude の活用」の見せ場は、製品の中の 4 つの係と決定的な検証、開発の進め方（[0015](0015-subagent-driven-development-with-codex.md)）に移った。
