# 0007 セレンディピティは埋め込みの距離で選ぶ（LLM に選ばせない）

- **Status:** Accepted
- **Date:** 2026-11-06

## Context

ダイヤル（セレンディピティ）は、次に流れるお便りが聴く人の好みに近いか遠いかを決めます。当初の設計では、Claude の選曲係が「同じ年・同じ土地・同じ気分」のつながりから候補を選ぶ案でした。計画の段階で枠決めはコードに移し、Phase 1 は「近く・隣・遠く」の三枠を規則で埋めていました。ただ、規則ではダイヤルの効きがはっきりしませんでした。

## Decision

作品ごとに、題名・作り手・年・種類だけから Workers AI の bge-m3 でベクトルを作り、距離で選びます。

- 聴く人の好みは、好みの作品のベクトルの平均。無ければ最近聴いた作品から作る。
- 候補の作品を好みからの距離で並べ、ダイヤルの位置の前後（±0.2。空なら少しずつ広げる）から無作為に 1 つ選ぶ。
- 7 日以内に聴いたお便りと、直近の枠の作品は外す。
- 好みが無ければ、無作為（世界のラジオと同じ選び方）。
- 距離は選ぶためだけに使う。画面・応答・ログ・DJ の言葉には出さない。

Claude には選ばせません。

## Consequences

- 選ぶたびのモデル呼び出しが無く、費用は作品ごとに 1 回のベクトルだけ。結果を再現でき、テストできる。
- 「数字で測らない」を守るため、遠さが外に出ていないことをテストで確かめている。
- ベクトルにお便りの本文は入れない。作品は説明の欄を持たず、確かな説明を返す検索先も無いので、作品の公開情報だけで作る（Phase 4 の実装時に設計書の追記 L を改めた）。
- 同じ作品のベクトルを同時に 2 回作りうる。費用がごく小さく結果も同じなので受け入れた（SECURITY.md）。
- 2026-11-07（追記 O）、好みは「送ったお便り」と「私も・一言を返したお便り」の作品から作ることにした。お便りが 3 通になるまで、ダイヤルは面に出したまま回せない。
