# 0010 1 枠 1 通

- **Status:** Accepted
- **Date:** 2026-11-07

## Context

Phase 4 で番組を 1 回 1 枠にしたあとも、1 つの枠には同じ作品のお便りを何通か入れていました。2 通目は「同じ作品に、別の人からも」のつなぎと手渡しだけで始まり、冒頭の一行も紹介もありませんでした。本番を見ると、2 通目から聴いた人には何の作品か分からず、同じ作品が長く続くこともありました。

## Decision

各お便りを独立した枠にします（設計書の追記 O、本人の指示）。

- 1 枠の並びは、つなぎ → 冒頭の一行 → 紹介 → 手渡し → お便り → 一言 → 反応。
- 同じ作品が続けて来ないよう、直近 3 枠の作品は避ける。
- 聴いたお便りは 7 日間避ける。どの局で聴いたものも数える。
- 1 つの作品の中では、聴いていないお便りを古い順に読む。
- 「同じ作品に、別の人からも」のつなぎは廃止する。

## Consequences

- どのお便りから聴き始めても、作品の名前と紹介が聞こえる。共有ページ（1 通の分だけのプレイヤー）とも形が揃った。
- 作品単位の「直近 30 回を外す」制限は、お便り単位の制限に置き換えた。作品が待つのは、そのお便りを全部聴いたときだけ。
- 出典の無い見つけた声は候補に入れない。1 通しか読まない枠が空になるため。
- 保存済みの古い回は、当時の文のまま描く（キーは外したが、描画は壊さない）。
- 候補が尽きたら、制限を「聴いたお便り → 直近 3 枠 → 直前の枠の作品」の順に戻す。直前の枠の作品は、ほかに候補が無いときだけ。
